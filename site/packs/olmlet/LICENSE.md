# Olmlet: license and credits

Original pixel art by Matthew Ruth's team for **Pixel Pet Pals**, a free, non-commercial fan project.
v3 (Oct 12, 2026): redrawn to sit closer to the in-game follower design, based on the approved redraw-v2 idle frame.
v4 (Oct 12, 2026): same approved art moved onto a 32x40 canvas (8px headroom) so happy/celebrate hop; `tools/olmlet_tall.py`.
Drawn from scratch as code (`tools/draw_pets_v3.py` + `redraw-v2/draw_v2.py`): polygons, ellipses and
hand-placed pixels on a 32x32 grid. In-game images were viewed only as visual reference for shape and colour;
no game sprites, models or textures were ripped, traced, sampled or downloaded into the art.

This is an original fan interpretation of a pet from Old School RuneScape.
